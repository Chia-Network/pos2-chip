## Code comments

Write comments in plain, natural language.
- Use short, complete sentences.
- Refer to actual variable or function names when explaining behavior.
- Explain the constraint or reason directly.
- Avoid semicolons, em dashes, jargon, and awkward shorthand in comment prose.
- Keep comments succinct without sacrificing clarity.

Good:
// Check that value fits in bit_count bits. If bit_count is zero, value must be zero.

Bad:
// The value must fit in the requested bits; zero bits can only hold zero.
